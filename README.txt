مخزني — تطبيق إدارة مخزون مشترك بين عدة أجهزة

المزايا:
- واجهة عربية RTL، الدينار العراقي، ولوحة تلخص المبيعات اليومية والأسبوعية والشهرية.
- منتجات بصور وتفاصيل موسعة، بحث نصي وبحث بصري تقريبي حسب الألوان.
- تسجيل البيع والشراء، وسجل حركات قابل للتعديل أو الإلغاء مع أثر تدقيق.
- دخول بالبريد وكلمة المرور. المدير يدير المنتجات والمشتريات والصلاحيات؛ الموظف يسجل البيع ويشاهد حركاته.
- تخزين مركزي على Supabase، وتحديث بيانات الأجهزة الأخرى عند إعادة التحميل أو خلال نحو 30 ثانية.
- سياسات قاعدة البيانات تتحقق من الصلاحيات؛ المفتاح المنشور في config.js مفتاح عام فقط.

الإعداد:
1) افتح supabase/SETUP_AR.md ونفذ خطوات إعداد قاعدة المشروع والمستخدم الأول.
2) ارفع جميع ملفات التطبيق إلى جذر مستودع GitHub، مع مجلد supabase.
3) لا تفعّل التسجيل العام للمستخدمين. أضف حسابات الموظفين من لوحة Supabase، ثم أدِر أدوارهم من التطبيق.

البيانات السابقة:
- التطبيق لا يرفع بيانات localStorage القديمة تلقائياً. تبقى محفوظة على هذا الجهاز في المتصفح؛ لا تمسح بيانات الموقع.
- بعد الإعداد يظهر للمدير زر استيراد منفصل مع عدد السجلات وطلب تأكيد قبل الإرسال. النسخة المحلية تبقى محفوظة، وكل مجموعة بيانات تُستورد مرة واحدة.

الحدود:
- يحتاج اتصالاً بالإنترنت لقراءة وكتابة المخزون المشترك؛ ملفات الواجهة وحدها تعمل دون اتصال.
- الصور محفوظة كنص داخل قاعدة البيانات، لذا راقب مساحة الخطة المجانية.
- إنشاء حساب جديد يتم من لوحة Supabase؛ المدير في التطبيق يستطيع تغيير دور الحسابات الموجودة.
- البحث بالصورة تقريبي ويقارن توزيع الألوان فقط.
- لا تضع أبداً كلمة مرور قاعدة البيانات أو Secret/service_role key في ملفات الموقع.
