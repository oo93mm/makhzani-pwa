مخزني — نسخة PWA أولية

المحتويات: واجهة عربية RTL، إضافة منتجات، صورة اختيارية، بحث نصي، تسجيل بيع وخصم الكمية، سجل حركة، تخزين محلي عبر localStorage، وملفات PWA الأساسية.

التشغيل:
1) ارفع محتويات المجلد إلى استضافة تدعم HTTPS.
2) افتح رابط الموقع في Safari على iPhone.
3) اضغط مشاركة ثم Add to Home Screen / إضافة إلى الشاشة الرئيسية.

تنبيهات مهمة:
- هذه نسخة تجريبية أولية وليست تطبيقاً مكتملاً أو مختبراً على كل الأجهزة.
- البيانات محفوظة في المتصفح على هذا الجهاز فقط؛ لا توجد مزامنة أو حسابات أو صلاحيات أو قاعدة بيانات مشتركة.
- لا تمسح بيانات Safari/الموقع قبل تصدير نسخة احتياطية (ميزة التصدير لم تُضف بعد).
- الصور محدودة إلى 1.2MB لكل صورة في هذه النسخة.
- لا تحتوي حالياً على مسح باركود أو بحث بالصورة أو إدارة عدة مخازن.
